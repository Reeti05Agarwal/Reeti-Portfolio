Based on our extensive conversation, here's a summary of your cyberpunk portfolio design vision:

## **Core Design Theme**
**Cybersecurity-Focused Cyberpunk Aesthetic** - A professional portfolio for a cybersecurity expert (Reeti Agarwal) that combines:
- Dark theme with neon accents (cyan, magenta, purple, blue)
- Terminal/command-line inspired elements
- Hacker/security-themed visual metaphors
- Professional but edgy presentation

## **Key Design Elements**

### **1. Color Palette**
- **Primary**: Black/Dark Gray backgrounds
- **Accents**: Cyan (#00ffff) & Magenta (#ff00ff) as primary neon colors
- **Secondary**: Purple, Blue, Green, Pink for variety
- **Text**: White with cyan/magenta highlights

### **2. Typography**
- **Font**: Monospace (Courier/Consolas/JetBrains Mono) for all text
- **Terminal-style** text formatting with `$` prefixes
- **Code-like** presentation of content

### **3. Visual Effects**
- **Glow Effects**: Neon shadows and borders
- **Scan Lines**: Animated lines moving across elements
- **Corner Decorations**: Cyberpunk-style corner borders
- **Binary/Matrix Effects**: Subtle binary code animations
- **Pulsing Animations**: Status indicators and active elements
- **Hover Effects**: Glow, scale, and color transitions

### **4. Component-Specific Design**

#### **Navbar**
- Terminal-style user prompt (`reeti@cyber:~$`)
- Corner decorations with cyan/magenta accents
- Subtle scan line animation
- Glitch effects on hover
- System status indicators

#### **Cards (Projects, Certificates, CTF, Hackathons)**
- **Background**: Black/dark gray with gradient overlays
- **Borders**: Neon-colored borders with glow effects
- **Corners**: Cyberpunk corner decorations
- **Headers**: Dynamic color schemes (rotating colors per card)
- **Content**: Organized with icons and labels
- **Tags**: Color-coded tech stack badges
- **Buttons**: Terminal-style buttons with `$` prefix

#### **Hero Section**
- Terminal command prompt (`$ whoami`)
- Cyberpunk profile picture with:
  - Circular frame with corner decorations
  - Floating security badges (eJPT, CTF)
  - Binary particle effects
  - Status indicators
- Dynamic badges with hover effects
- Social media buttons with platform-specific colors

#### **Buttons**
- Terminal-style with `$` prefix
- Platform-specific colors:
  - Cyan for contact/actions
  - Green for "Read More"
  - Purple for GitHub
  - Magenta for secondary actions
- Glow effects on hover
- Dynamic width (50/50 or 100% based on availability)

#### **Section Headings**
- Terminal command format
- Directory + command structure
- Color-coded glow effects
- Status indicators
- Description in comment format (`// text`)

### **5. Layout Principles**
- **Grid-based** card layouts (2-3 columns responsive)
- **Consistent spacing** with cyber borders
- **Visual hierarchy** through size, color, and typography
- **Mobile-responsive** with stacked layouts
- **Interactive elements** with meaningful hover states

### **6. Interactive Features**
- **AI Chatbot**: Terminal-style popup with cyberpunk styling
- **Dynamic Content**: Cards show/hide sections based on data availability
- **Hover Animations**: All interactive elements have cyberpunk hover effects
- **Color Rotation**: Cards use rotating color schemes for visual interest

### **7. Content Strategy**
- **Terminal Metaphor**: Everything presented as system commands/output
- **Security Focus**: Encryption indicators, verification badges
- **Professional**: Clean layout despite cyberpunk styling
- **Data-Driven**: Dynamic content rendering based on JSON data

### **8. Unique Touches**
- **Floating Badges**: Security certifications floating around profile
- **Binary Particles**: Subtle 0/1 animations in backgrounds
- **Status Indicators**: "ACTIVE", "VERIFIED", "ONLINE" badges
- **Corner Accents**: Cyan/magenta corner decorations on all cards
- **Scan Lines**: Horizontal lines that animate on hover

## **Design Philosophy**
1. **Professional First**: Cyberpunk elements enhance, not overwhelm
2. **Consistency**: Unified design language across all components
3. **Functionality**: All effects serve a purpose (indicators, hierarchy)
4. **Performance**: Smooth animations without being resource-heavy
5. **Accessibility**: Good contrast despite dark theme

## **Tech Stack Implications**
- Tailwind CSS for styling
- Framer Motion for animations
- Next.js Image optimization
- TypeScript for type safety
- Component-based architecture

This design creates a cohesive, memorable portfolio that immediately communicates your cybersecurity expertise while providing an engaging user experience. It's professional enough for recruiters but edgy enough to stand out in the tech space.
